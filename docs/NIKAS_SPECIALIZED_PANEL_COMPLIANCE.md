Минимальная заявленная HA: **2026.10.4**, baseline API, прочитанный при проверке. [Официальная реализация Store](https://github.com/home-assistant/core/blob/2026.10.4/homeassistant/helpers/storage.py) проверена: стандартный Store может возвращать None после переноса повреждённого JSON в .corrupt и логировать WriteError без исключения. Поэтому чтение журнала проверяет действительный файл в executor, запись включена с atomic_writes и подтверждается чтением диска.

Локальный PASS не означает доставку HACS, проверку живого оборудования или успешный перенос фактического журнала пользователя.
