# BARRIER resource bars

The user marked three positions under the BARRIER cartridge deadlines in the Overview screenshot and requested bars matching the main-filter indicator.

Each stage gets its own remaining-calendar-resource bar. Calculate its percentage from the saved replacement date and the backend deadline/remaining days; do not substitute water volume or a fixed number of days per month. Use the existing stage status for color and retain its deadline text. Missing/invalid dates, missing days or unknown status produce an unknown neutral track, not a measured zero. Due/overdue known intervals show zero remaining. Read failure/disconnection clears prior values.

Reuse the current progress styling and patch existing DOM nodes. Keep the five-tab shell, maintenance calculations, write API and journal unchanged. The BARRIER subtitle identifies the time basis.

The alternative of using the main-filter volume percentage would misrepresent three separately scheduled cartridges. Reusing backend calendar deadlines also preserves automatic softening periods and short calendar months.

The regeneration question is answered with the existing Ёлка → «Остаток, очистка бака и регенерации» form: «Дата события», completed-cycle confirmation, then «Записать завершённый цикл». No date is invented or written to the live journal.
