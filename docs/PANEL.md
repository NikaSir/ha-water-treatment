# Контракт панели «Водоподготовка»

Владелец `water_treatment`; маршрут `/dashboard-water-treatment`; web component `nikas-water-treatment-panel`. Родительский маршрут заголовка `/home/overview`. Вкладки: Обзор, Фильтры, Ёлка, Жёсткость. Обзор — стартовая вкладка новой панели; сохранённый выбор пользователя имеет приоритет. Давление и статистика находятся в соседнем приложении учёта воды.

Независимое чтение питьевого водомера HA; API журнала `water_treatment/filters` с проверкой прав администратора на изменение и ревизии. Накопительные показания и Recorder не изменяются. [Переход и хранение данных](WATER_SPLIT_MIGRATION.md).

Обзор читает тот же снимок `water_treatment/filters`: ресурс магистрального, три срока БАРЬЕР, журнал регенераций, оценку соли и полную историю GH. Для GH выбирается последняя запись точки `softener`, с порядком добавления при одинаковой дате. Дата цикла сама по себе не подтверждает результат умягчения. Форма обслуживания открывается по нажатию; обзор не выполняет записей и физических команд.

Модель `frontend/src/overview-model.js` отделена от статической разметки и точечного обновления `overview-ui.js`; обе входят в единый собранный JS. Три PNG находятся в `frontend/assets/`, их URL содержит полную UI-версию. При ошибке чтения и отключении HA данные обзора становятся неизвестными; успешный снимок обновляет существующие узлы.
